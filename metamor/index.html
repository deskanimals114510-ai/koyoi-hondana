元の作品『メタモルフォーゼの縁側』(鶴谷香央理)

主人公は二人です。一人は、書店でアルバイトをする17歳の女子高生・佐山うらら。もう一人は、夫に先立たれて暮らす75歳の市野井雪さんで、ある日偶然BL漫画を手に取ります。BLという共通の趣味をきっかけに、年の差58歳の二人が友情を育てていく話です。夫との死別や老いも出てきますが、重くはありません。全5巻で完結しています。

ここでは「年の離れた二人の距離感」と「好きなことでつながる関係」のどちらかが重なる4冊を選びました。漫画が3冊とコミックエッセイが1冊です。

映像化(2026年11月時点):2022年6月に実写映画が公開されました(芦田愛菜さん・宮本信子さん出演)。

海が走るエンドロール

海が走るエンドロール

たらちねジョン / 秋田書店

いくつになっても始めていい、と思いたい夜に。

主人公の茅野うみ子は65歳を過ぎた女性で、夫と死別しています。何十年ぶりかに足を運んだ映画館で、映像を学ぶ美大生の海と知り合ったことをきっかけに、自分は映画を「作る側」に回りたいのだと気づきます。うみ子は美大に入り、映画づくりに挑みます。全9巻で完結しています。

夫と死別した女性が、年の離れた若者との出会いをきっかけに新しい世界へ入る、という流れが雪さんと重なります。雪さんとうららはBLを読むことでつながりますが、うみ子は作る側へ進みます。

読む前に: 夫との死別が出発点で、老いも描かれます。重い描写は少なめです。

違国日記

違国日記

ヤマシタトモコ / 祥伝社

年の離れた相手と、ゆっくり仲良くなる話を読みたい夜に。

35歳で人見知りの小説家・高代槙生が、姉夫婦の葬式で親戚の間をたらい回しにされていた15歳の姪・朝を勢いで引き取ります。親子でも友達でもない二人の同居を描いた話で、全11巻で完結しています。

雪さんとうららのように、年齢も立場も違う二人が対等に向き合うところが似ています。こちらは同居で、出発点に家族の死があるぶん、メタモルフォーゼの縁側より重いテーマを含みます。

読む前に: 朝の両親の事故死と喪失が出発点で、親子関係の確執も描かれます。

ルックバック

ルックバック

藤本タツキ / 集英社

好きなことを、誰かと一緒にやれた日々を思い出す夜に。

小学4年生の藤野は、学年新聞の4コマ漫画で人気でしたが、不登校の同級生・京本の絵のうまさに打ちのめされます。卒業証書を届けに行った日に京本が自分のファンだったと知り、二人で漫画を描き始めます。そこからの10年以上を1冊で描いた読み切りです。

漫画という好きなものを通して二人が結びつく点が、BLで結ばれた雪さんとうららと重なります。こちらは同級生の二人で、読む側ではなく描く側の話です。4冊の中でいちばん重く、明るい気分の夜には向きません。

読む前に: 通り魔による殺傷事件と、主要人物の死が描かれます。

大家さんと僕

大家さんと僕

矢部太郎 / 新潮文庫

ずっと年上の人と、お茶を飲みたい夜に。

お笑い芸人の「僕」が、都内の木造2階建ての家の2階を借りて暮らします。1階に住む上品な高齢の大家のおばあさんと、お茶や食事などの日々のやり取りを重ねていく、実話ベースのコミックエッセイです。続編に『大家さんと僕 これから』があります。

若い側が男性の芸人になりますが、高齢の女性と年の離れた相手が少しずつ親しくなる形は、雪さんとうららそのものです。趣味ではなく住まいでつながる点が違います。

読む前に: 大家さんの老いが描かれます。続編『これから』では別れも描かれます。
