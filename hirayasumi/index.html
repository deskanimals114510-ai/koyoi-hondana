元の作品『ひらやすみ』(真造圭伍)

29歳のフリーター・ヒロトが近所のおばあちゃんから平屋を譲り受け、山形から上京した18歳のいとこ・なつみと暮らし始める話です。阿佐ヶ谷や高円寺の町を季節がゆっくり通り過ぎ、周りの人たちとの日常が続いていきます。冒頭にはおばあちゃんとの別れがありますが、全体は穏やかな日常ものです。

ここでは「急がない暮らし」と「年の離れた相手との同居や付き合い」が似ている4冊を選びました。

凪のお暇

凪のお暇

コナリミサト / 秋田書店

仕事を辞めたい、とまでは言わなくても、少し休みたい夜に。

28歳の会社員・凪は、空気を読みすぎて周りに合わせ続けた末、職場で過呼吸を起こして倒れます。仕事を辞め、引っ越し、交際相手からも離れて、元手100万円で人生をいったんリセットする「お暇」に入る話です。全12巻で完結しています。

ヒロトの平屋暮らしと同じく、肩の力を抜いた暮らしが軸にあります。違うのは、凪のほうは「抜く」こと自体に苦労する点。ひらやすみが最初から静かなら、こちらは静けさに辿り着くまでを描きます。

読む前に: 過呼吸や職場の同調圧力、元恋人の支配的な言動、母親との確執が描かれます。

大家さんと僕

大家さんと僕

矢部太郎 / 新潮文庫

階下に誰かの気配があればいいのに、と思う夜に。

お笑い芸人の「僕」が、都内の木造2階建ての2階を借りて暮らし、1階に住む上品な高齢の大家のおばあさんとお茶や食事を重ねていく、実話ベースのコミックエッセイです。手塚治虫文化賞の短編賞を受けています。

芸人の男性と高齢の女性の組み合わせという点で、ヒロトと平屋のおばあちゃんを思わせます。実話のコミックエッセイで一話が短く、寝る前に数ページだけ読む使い方ができます。

読む前に: 大家さんの老いや入院の場面があります。

作りたい女と食べたい女

作りたい女と食べたい女

ゆざきさかおみ / KADOKAWA

ひとり分を作る気力がない夜に、作りすぎる人の話を。

少食だけれど料理好きで一人暮らしの野本さんは、つい作りすぎてしまいます。隣の隣の部屋に住む、よく食べる春日さんを夕食に誘ったことから、二人の交流が始まる話です。

ひらやすみと同じく、誰かと食卓を囲む時間が暮らしの中心にあります。こちらは女性同士の恋愛が描かれ、実家との確執や性別役割への違和感といった、女性の生きづらさにも向き合う作品です。

メタモルフォーゼの縁側

メタモルフォーゼの縁側

鶴谷香央理 / KADOKAWA

好きなものの話を、誰かと存分にしたい夜に。

夫に先立たれた75歳の市野井雪さんが、偶然BL漫画に出会います。書店でアルバイトをする17歳の佐山うららと、BLという共通の趣味をきっかけに、年の差58歳の友情を育てていく話です。全5巻で完結しています。

ヒロトとなつみは血縁ですが、こちらは趣味だけでつながった他人同士。年の差のある二人がお互いを対等に扱うところが似ています。夫との死別や老いも出てきますが、描き方は重くありません。
